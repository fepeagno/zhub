Sobre a trilha

Aprenda a desenvolver aplicações modernas no ecossistema SAP utilizando o RESTful ABAP Programming Model (RAP), o modelo recomendado pela SAP para extensões e desenvolvimento alinhado ao Clean Core. Nesta trilha, você entende os principais conceitos do RAP, desde a modelagem com CDS Views, criação de comportamentos, exposição de serviços e construção de aplicações com Fiori Elements, preparando-se para atuar em projetos modernos de S/4HANA e ABAP Cloud.

CDS ViewsComportamentos RAPExposição de serviçosFiori ElementsABAP CloudS/4HANA

O que você vai aprender

  • ✓Configurar o ambiente de desenvolvimento ABAP Cloud (Eclipse/ADT, BTP Trial, ABAP Environment).
  • ✓Modelar dados com CDS Views: Define View Entities, Table Functions, Abstract e Custom Entities.
  • ✓Aplicar funções, associations e joins dentro de CDS Views.
  • ✓Construir Business Objects RAP com as camadas Basic, Composite e Consumption.
  • ✓Implementar operações CRUD via Behavior Definitions, BAPIs e Actions.
  • ✓Expor serviços OData e consumi-los via Postman e Fiori Elements.
  • ✓Publicar aplicações no Launchpad e realizar o deploy no Business Application Studio (BAS).

Público-alvo

Desenvolvedores ABAP e arquitetos técnicos que já possuem base no ecossistema SAP e querem se especializar no modelo RAP, principal caminho de desenvolvimento recomendado pela SAP para Clean Core e ABAP Cloud.

Pré-requisitos

Conhecimento básico de ABAP e do ecossistema SAP (recomenda-se a trilha SAP CORE - Foundations). Familiaridade com lógica de programação orientada a objetos é desejável.
