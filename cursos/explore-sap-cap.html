Sobre a trilha

Aprenda a desenvolver aplicações modernas na SAP BTP utilizando o SAP CAP (Cloud Application Programming Model), o framework da SAP para criação de soluções cloud, extensíveis e integradas ao ecossistema SAP. Nesta trilha, você entende os principais conceitos do CAP, como modelagem de dados, criação de serviços, APIs, integrações e desenvolvimento de aplicações preparadas para cenários reais de negócio na SAP Business Technology Platform.

SAP BTPModelagem de dadosServiçosAPIsIntegrações

O que você vai aprender

  • ✓Configurar o ambiente de desenvolvimento CAP (Node.js, VS Code, Business Application Studio).
  • ✓Revisar fundamentos de JavaScript necessários para o desenvolvimento CAP (tipos, funções, promises, ES6).
  • ✓Modelar dados e serviços com CDS: entidades, aspects, annotations, associations e compositions.
  • ✓Implementar Custom Handlers e consumir dados via OData e Mock Data.
  • ✓Integrar o CAP com sistemas SAP on-premise via Cloud Connector e Destinations.
  • ✓Construir um projeto real de ponta a ponta (Lab2Cash), incluindo enriquecimento de dados, eventos e alertas.
  • ✓Criar aplicações com SAP Build Apps e publicar via API Proxy.

Público-alvo

Desenvolvedores e arquitetos que querem dominar o SAP CAP para construir aplicações cloud extensíveis, integradas ao ecossistema SAP e alinhadas à estratégia Clean Core na SAP BTP.

Pré-requisitos

Conhecimento básico de programação (idealmente JavaScript) e noções do ecossistema SAP. Recomenda-se familiaridade prévia com o SAP BTP.
