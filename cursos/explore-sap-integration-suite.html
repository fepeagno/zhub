Sobre a trilha

Nesta trilha, você vai conhecer os principais conceitos do SAP Integration Suite e entender como essa solução apoia a integração entre sistemas, aplicações, dados e processos dentro do ecossistema SAP. Ao longo do conteúdo, são abordados temas como fundamentos de integração, APIs, conectividade, eventos, segurança, monitoramento e boas práticas para criação de integrações modernas. A proposta é ajudar você a compreender como o Integration Suite pode ser utilizado em cenários reais de projeto, conectando soluções SAP e não SAP de forma mais eficiente, escalável e alinhada às necessidades das empresas.

Fundamentos de integraçãoAPIsConectividadeEventosSegurançaMonitoramento

O que você vai aprender

  • ✓Entender os conceitos de APIs e protocolos web (REST, SOAP, GraphQL) e integração moderna (eventos, webhooks).
  • ✓Construir iFlows no SAP Cloud Integration (CPI): headers, properties, body e conectores HTTP/OData/SFTP/SOAP.
  • ✓Aplicar Value Mapping, Message Mapping, XSLT e Groovy Script em cenários de integração.
  • ✓Publicar e proteger APIs com o SAP API Management (proxies, OAuth2, quotas, mediation e extension policies).
  • ✓Trabalhar com arquitetura orientada a eventos no Event Mesh (tópicos, subscrição, consumo).
  • ✓Conectar sistemas externos com Open Connectors.
  • ✓Construir um projeto final de integração ponta a ponta, com enriquecimento de dados, contratos, notificações e exposição via API Proxy.

Público-alvo

Consultores, desenvolvedores e arquitetos de integração que atuam ou vão atuar com o SAP Integration Suite em projetos de conectividade entre sistemas SAP e não SAP.

Pré-requisitos

Não é necessário conhecimento prévio em ferramentas de integração. Recomenda-se noções básicas de APIs e do ecossistema SAP.
