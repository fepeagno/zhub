## Recommended execution order

1. **001** — CSS-only, touches `index.html` + `assets/zhub.css`. No dependency on the others; do it first since it's the highest-severity and purely additive (a new media query block).
2. **002** — JS-only, touches `index.html` + `assets/zhub.js`. Independent of 001 (different rules in different sections of each file), but do it right after 001 so both accessibility/frequency fixes land together before the more surgical performance/easing plans.
3. **003** — JS-only, touches `index.html`'s hero canvas IIFE exclusively. No overlap with 001 or 002 (different script blocks), but note it *also* adds its own local `prefers-reduced-motion` check (scoped to the canvas only) — this is intentional and not a duplicate of 001, since 001 does not touch any JS.
4. **004** — CSS-only, FAQ accordion. Independent of 001-003.
5. **005** — CSS-only, FAQ icon. Touches the same `<style>` block as 004 (both in the "FAQ" CSS section) but a different rule (`.faq-icon` vs `.faq-body`) — no line overlap, safe to do in either order relative to 004, listed last since it's LOW severity.

## Dependencies

None of the five plans edit the same lines as another, so they can be applied in any order without conflicts — the order above is purely by severity/leverage, not a hard requirement.
